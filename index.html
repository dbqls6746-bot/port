About Me

동작하는 코드를 넘어, 시스템의 안정성과 흐름을 집요하게 추적합니다.

단순히 화면을 띄우거나 기능을 구현하는 데 그치지 않고, “데이터가 어떤 흐름을 거쳐 사용자에게 도달하는가?”에 끊임없이 질문을 던집니다. 현장에서 장비와 설비를 다루며 체득한 '작은 오차가 전체 시스템을 멈춘다'는 기본 원칙을 소프트웨어 아키텍처와 데이터베이스 설계에도 그대로 적용하고 있습니다.

백엔드에서는 Java와 Spring(Spring Boot, MVC)을 기반으로 데이터베이스(Oracle DB, MyBatis) 모델링 및 RESTful API 서버 구축에 강점을 두고 있습니다. 여기에 머무르지 않고 JSP, Tailwind CSS, React 등을 적극 활용하여 사용자 경험까지 매끄럽게 연결하는 실용적인 풀스택 개발을 지향합니다.

팀 프로젝트에서 팀장을 맡아 요구사항 정의부터 DB 스키마 설계, 일정 조율까지 프로젝트 라이프사이클 전반을 리딩한 경험이 있습니다. 명확한 커뮤니케이션과 꼼꼼한 기록을 통해 동료들과 함께 문제를 해결하고 어제보다 더 견고한 프로덕트를 만드는 과정에 큰 보람을 느낍니다.
